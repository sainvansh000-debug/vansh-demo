# EconoCausal -- Day 1

## Workflow

-   Collect customer transaction and discount data.
-   Clean and preprocess data using Pandas and NumPy.
-   Perform Exploratory Data Analysis (EDA).
-   Estimate discount effects using Double Machine Learning and EconML.
-   Validate causal assumptions using DoWhy.
-   Optimize discount allocation using SciPy.
-   Develop an interactive dashboard using React.js and Plotly.
-   Test and evaluate the final results.
